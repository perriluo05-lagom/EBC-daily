# 📬 EBC Daily · 每日资产资讯邮件

> **E**TF · **B**ond · **C**onvertible —— 每个交易日早晨，一封「数据 → 解读 → 参考思路」递进呈现的资讯邮件，落地到你的邮箱。
> 面向初入市场的个人投资者，文风专业但不说教，用**真实可查证的数据**支撑每一个判断，由 GitHub Actions 云端定时推送。

---

## ✨ 项目特点

- 🚫 **绝不编造数据** —— 所有数值来自可查证公开渠道（沪深交易所、中证指数公司、中国债券信息网、中国货币网、东方财富、新浪财经、集思录等）；取不到的字段如实标注「数据暂缺」，绝不填默认值或臆测。
- 🏷️ **来源逐条可溯** —— 每个关键数据后附 `(来源：XX)`，读者可一键核对。
- 🧠 **规则化解读，非主观喊单** —— 解读与参考思路由透明规则模板基于真实数据推导，措辞统一用「可关注 / 可以留意」，不含绝对化指令。
- ☁️ **全云端自动运行** —— GitHub Actions 定时触发，本地零运维；非交易日自动跳过。
- 🛡️ **优雅降级** —— 单个数据源失败只影响该字段，不中断整体流程。

## 🚀 快速开始（本地）

### 1. 安装依赖

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows（Linux/macOS 用 source .venv/bin/activate）
pip install -r requirements.txt
```

### 2. 试跑（不发邮件）

```bash
# 默认今天；不判交易日、不发邮件，打印 Markdown 并写入 output/EBC-Daily-YYYY-MM-DD.md
python main.py --dry-run

# 指定报告日期
python main.py --dry-run --date 2026-07-31
```

试跑后查看 `output/EBC-Daily-2026-07-31.md` 即可预览邮件正文效果。

### 3. 真正发送（需配置邮箱）

复制 `.env.example` 为 `.env`，填入 QQ 邮箱授权码等信息，然后：

```bash
python main.py        # 自动判断交易日；非交易日跳过
```

## ☁️ 云端部署（GitHub Actions）

云端运行无需本地开机，由 GitHub 定时触发，是推荐的长期使用方式。

### 第 1 步：推送代码到 GitHub

将本仓库推送到你的 GitHub 仓库（见文末「上传到 GitHub」）。

### 第 2 步：配置邮件 Secrets

进入仓库 **Settings → Secrets and variables → Actions → New repository secret**，依次添加：

| Secret 名 | 值 | 说明 |
|---|---|---|
| `MAIL_HOST` | `smtp.qq.com` | QQ 邮箱 SMTP 主机 |
| `MAIL_PORT` | `465` | SSL 端口 |
| `MAIL_USER` | 你的 QQ 邮箱 | 发件账号 |
| `MAIL_PASS` | QQ 邮箱**授权码** | ⚠️ 不是登录密码；在 QQ 邮箱「设置 → 账户 → 开启 IMAP/SMTP」后生成 |
| `MAIL_FROM` | 同 `MAIL_USER` | 发件地址 |
| `MAIL_TO` | 收件人邮箱 | 多个用英文逗号 `,` 分隔 |

### 第 3 步：手动试跑

进入仓库 **Actions** 标签 → 左侧选「EBC Daily 邮件推送」→ 右上「Run workflow」：

- 勾选 `dry_run` 可先生成不发送，产物在 Artifacts（`ebc-daily-output`）里下载预览；
- 不勾选则真实发送邮件。

### 第 4 步：享受自动推送

- ⏰ **定时触发**：北京时间 **周一至五 08:00**（GitHub cron `0 0 * * 1-5`，可能有 5–30 分钟延迟）。
- 📅 **节假日**：由 `main.py` 内交易日历自动判断并跳过，不发空邮件。
- 🔁 **保活**：GitHub 若 60 天无 commit 会停用定时任务；`keepalive.yml` 每周自动做一次 trivial commit 保持活跃。

## ❓ 常见问题

**Q：终端运行显示「采集失败 / 数据暂缺」是怎么回事？**
- 若运行 `python main.py`（不带 `--dry-run`）在**周末或节假日**，会看到「非交易日，跳过推送」——这是**正常行为**，不是报错。
- `--dry-run` 会跳过交易日判断强制采集。个别字段（如涨跌家数、ETF 资金流）依赖东方财富接口，本地若处代理/网络受限环境可能取不到而显示「数据暂缺」，云端 GitHub Actions 环境通常正常。

**Q：为什么删除了「北向资金」？**
沪深交易所自 2024-08-19 起停止日度净流入/流出披露，已无可靠数据源，故移除该字段，绝不以替代值冒充。

**Q：为什么用 Shibor 1周 而不是 DR007？**
akshare 无 DR007 稳定直取接口；Shibor 1周同为银行间资金面指标且可稳定获取，并明确标注来源，避免误导。

**Q：邮件没按时收到？**
- GitHub cron 可能有 5–30 分钟延迟；
- 确认仓库 60 天内有 commit（`keepalive.yml` 已自动保活）；
- 在 Actions 页面查看运行日志定位。
